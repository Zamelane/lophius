# extension

Chrome MV3 extension scaffold (React + TypeScript + SCSS).

## Setup

```bash
bun install
```

## Develop

```bash
bun run dev
```

Load unpacked from `dist/` in `chrome://extensions`.

## Build

```bash
bun run build
bun run typecheck
```

Popup navigation example: Home (`#/`) ↔ Settings (`#/settings`).
